LiMBS1.0 Membrane Specification Generator

Create a standardized LiMBS1.0 description of a membrane system. Select the molecular resolution, membrane geometry, leaflet composition, system dimensions, solvent, and ionic conditions. For supported coarse-grained systems, LiMBS will show the appropriate construction interface automatically.

1. Molecular Resolution

Select the molecular representation used for the LiMBS species definitions.

2. Membrane Geometry

Select a planar membrane or vesicle.

3. Leaflet Composition Mode

Count mode records absolute molecule numbers. Ratio mode records relative leaflet composition.

In ratio mode, decimal values such as 0.20 and 0.80 are allowed. Upper/outer and lower/inner leaflet compositions are entered independently.

4. Lipid Composition

Enter a non-zero value for each lipid present in the membrane. Zero-valued lipids are omitted from the generated LiMBS specification.
